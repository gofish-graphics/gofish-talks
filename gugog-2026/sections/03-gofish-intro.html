Say: GoFish is my attempt at those verbs. In a language with verbs, you can build new structures from old ones, using a fairly stable set of composition mechanisms. It's a compositional language for visual structure, open source. Here are two of its API surfaces side by side. On the left, the core: four planets as circle marks, spread lays them out in a row, and enclose draws the background around them. On the right, a stacked bar chart: the same spread lays out the lakes, and stack piles the species inside each one.

Two surfaces on one core (one sentence): "These are two surfaces on one core. The chart level gives short specs for common charts, and it is built out of the low-level core of marks and relations." These are the verbs that part 2 asks for, at work. Obstacle 4c, a small language against a big one, comes back to this split.

  spread(
    { dir: "x", alignment: "middle", ... },
    data.map((d) => circle({ r: d.r, ... }).name(d.name))
  ),
]).name("planets");

const label = text({ text: "Mercury", ... }).name("label");

layer([planets, label])
  .relate(({ mercury, planets, label }) => [
    Constraint.align({ x: "middle" }, [mercury, label]),
    Constraint.distribute({ dir: "y", ... }, [planets, label]),
    arrow({ ... }, [label, mercury]),
  ])
