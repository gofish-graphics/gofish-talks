spread is align plus distribute

enclose({ ... }, [
  layer([
    circle({ r: 15, fill: "#F5E3C8", ... }).name("mercury"),
    circle({ r: 36, fill: "#D2913C", ... }).name("venus"),
    circle({ r: 38, fill: "#3E8CCC", ... }).name("earth"),
    circle({ r: 21, fill: "#F4BC80", ... }).name("mars"),
  ]).relate(({ mercury, venus, earth, mars }) => [
    Constraint.align({ y: "middle" }, [mercury, venus, earth, mars]),
    Constraint.distribute({ dir: "x", spacing: 50 }, [mercury, venus, earth, mars]),
  ]),
])

Say: "And here is the same picture, with spread written as two relations. A relation sets only some properties of a set of marks. align gives the planets a shared position, the same middle in y. distribute sets the spacing between them in x. Neither one places the planets by itself, but together they do. That is how GoFish defines spread. An operator places its marks completely, and it is made of relations."

Lead into the answer: "Now let's write the three grammars from before in GoFish. First Atom."

If asked: this is the real definition, not a teaching version. In the GoFish source, spread builds a layer over its children and relates them with Constraint.align on the other axis and Constraint.distribute along its direction. Its defaults are a baseline alignment and 8 pixels of spacing. stack is the same spread with the marks glued together, with no gaps.

Source: packages/gofish-graphics/src/ast/graphicalOperators/spread.tsx in the GoFish repo, the same code as nightly 20261106. Both renders are live.
