    "aspect_ratio": "fillX",

GoFish

chart(titanicPassengers)
  .flow(
    spread({ by: "pclass", dir: "x",
      spacing: 24, alignment: "end" }),
    derive(rows => orderBy(rows,
      ["survived"], ["desc"])),
    derive(rows => chunk(rows, 14)),
    spread({ dir: "y", spacing: 2, reverse: true }),
    spread({ dir: "x", spacing: 2 })
  )
  .mark(circle({ r: 4, fill: "survived" }));

The PiCCL bottle chart in GoFish

chart(bottleData, { axes: false })
  .flow(spread({ by: "category", dir: "x", ... }))
  .mark(layer([
    paint({ blendMode: "color" }, [
      image({ href: bottlePng, h: v(100) }),
      rect({ h: "amount", ... }),
    ]).name("bottle"),
    rect({ h: 1, y: "amount", ... }).name("line"),
    text({ text: (d) => `${d.amount}%`, ... }).name("label"),
  ]).relate(({ bottle, line, label }) => [
    Constraint.align({ x: "start" }, [bottle, line]),
    Constraint.distribute({ dir: "y", ... }, [line, label]),
    Constraint.align({ x: "end" }, [label, line]),
  ]))

Bottle chart from PiCCL · Shi et al., IEEE VIS 2025

Say: This bottle chart comes from PiCCL, by Shi and others at VIS 2025. It is built from the parts we just saw. A picture of a bottle gets a green rectangle painted onto it, as tall as the number, and a line and a label mark the top of the green. In GoFish, those same parts are a few verbs and marks. spread repeats the bottle for each category. paint puts the green rectangle onto the bottle picture. layer adds the line and the label, and relate lines them up with the top of the green. So PiCCL's idea fits into GoFish as a few verbs and marks, and you do not need a new language for it.

The point of the two comparisons: Atom and PiCCL can be written in one language. Written that way, they share most of their structure, and the differences are small parts you can point to.
