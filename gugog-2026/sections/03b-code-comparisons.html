Add relations to place a line and a label

chart(bottleData, { axes: false })
  .flow(spread({ by: "category", dir: "x", ... }))
  .mark(layer([
    atop({ blendMode: "color" }, [
      image({ href: bottlePng, h: v(100),
              filter: Filter.grayscale }),
      rect({ h: "amount", fill: "lime", ... }),
    ]).name("bottle"),
    rect({ h: 1, y: "amount", ... }).name("line"),
    text({ text: (d) => `${d.amount}%`, ... }).name("label"),
  ]).relate(({ bottle, line, label }) => [
    Constraint.align({ x: "start" }, [bottle, line]),
    Constraint.distribute({ dir: "y", ... }, [line, label]),
    Constraint.align({ x: "end" }, [label, line]),
  ]))

relations place one mark against another

Say: "Now the second part, relations. We add a line and a label at the top of the green. A relation sets only some properties of a set of marks. The tinted lines are the relations. align lines up the line with the bottle, and distribute puts the label just above the line. Neither one places a mark by itself, but together they do. The operators and the relations mix in one spec, because they are one language."

The point of the two comparisons: these are the same kinds of pictures from earlier, now written with one shared set of operators and relations. The same spread does the work of Atom's gridxy and of PiCCL's repeating. PiCCL's compositing fits in as one more operator, so you do not need a new language for it.
