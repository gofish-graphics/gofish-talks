  • This is the usual answer for the middle of the compression picture from the opening. Every chart is written directly against the same fixed nouns: marks, encoding channels, coordinate transforms, and the rest of the grammar's categories.
  • There is no way to define new words from old ones. The charts here are ones from the splash wall, and each one goes straight down to the same layer.
  • Click. A fixed set of nouns gives a finite number of combinations. To reach a chart outside them, like this croissant chart, you have to add a new noun to the core, such as a new geom or a new coordinate system. So the core keeps growing. That is the opposite of the compression from the opening.
  • Say: "In the traditional grammar of graphics, the only way to grow the language is to add a new primitive. What if we could build new structures from the ones we already have?"
  • Verbs are what make that possible. The tree slide near the end answers the question on this slide.
