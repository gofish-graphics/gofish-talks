Say: GoFish is my attempt at those verbs. It's a compositional language for visual structure, open source. Two quick examples. On the left, four planets: ellipse is the noun, and spread is a verb that lays them out in a row. On the right, a stacked bar chart: the same spread lays out the lakes, and stack piles the species inside each one.

Two levels (plant big vs. small here, one sentence): "GoFish has two levels. The chart level is a big language: short specs for common charts. Underneath is a small core, marks and relations, and the chart level is built out of it. So GoFish already has both a big language and a small one, layered. I'll come back to that tradeoff at the end." Section 5 ("the open one: big vs. small") calls back to this slide.

Add one thing, get a new graphic

core · + a text mark and a relation

layer([
  spread(
    { dir: "x", spacing: 50, alignment: "middle" },
    map(planets, (planet) =>
      ellipse({
        w: planet.radius * 2,
        h: planet.radius * 2,
        fill: planet.color,
        stroke: "#333",
        strokeWidth: 3,
      }).name(planet.name)
    )
  ),
]).relate(({ Mercury }) => [
  spread({ dir: "y", spacing: 60, alignment: "middle" }, [
    text({ text: "Mercury" }),
    Mercury,
  ]),
])

chart level · + a ribbon

chart(seafood)
  .flow(
    spread({ by: "lake", dir: "x", spacing: 64 }),
    stack({ by: field("species").sort("count"), dir: "y" }),
  )
  .mark(rect({ h: "count", fill: "species" }))
  .layer(ribbon({ by: "species", opacity: 0.8 }))

Say: Now add one thing to each. On the left, a label: we name the planets, put them in a layer, and .relate() says the text sits above Mercury. That's a new mark and a new relation. On the right, one line, ribbon, connects each species across the lakes, and the stacked bars become a ribbon chart. Verbs take graphics and compose them into bigger graphics.

The highlights mark only what changed from the previous slide. On the left, the rest of the code moved one indent level when it went inside the layer; that is not highlighted.
